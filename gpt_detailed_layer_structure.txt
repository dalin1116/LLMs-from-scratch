╔═══════════════════════════════════════════════════════════════════════════════════════════════════════════════╗
║                                        KEY ARCHITECTURAL FEATURES                                             ║
╚═══════════════════════════════════════════════════════════════════════════════════════════════════════════════╝

1. RESIDUAL CONNECTIONS (Shortcut Connections):
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Two residual connections per Transformer block                                                        │
   │ • Total: 24 residual connections (12 blocks × 2)                                                        │
   │ • Purpose: Enable gradient flow in deep networks, prevent vanishing gradients                           │
   │ • Pattern: output = F(x) + x, where F is the sub-layer (attention or feed-forward)                     │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

2. LAYER NORMALIZATION:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Pre-Norm architecture: LayerNorm applied BEFORE sub-layers                                            │
   │ • Formula: LN(x) = γ · (x - μ) / √(σ² + ε) + β                                                         │
   │ • Normalizes across the feature dimension (768), per sample, per token                                  │
   │ • γ (scale) and β (shift) are learnable parameters                                                      │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

3. MULTI-HEAD ATTENTION MECHANISM:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • 12 parallel attention heads                                                                            │
   │ • Each head: 64 dimensions (768 / 12 = 64)                                                              │
   │ • Scaled dot-product attention: Attention(Q,K,V) = softmax(QK^T / √d_k) V                              │
   │ • Causal masking: prevents attending to future positions                                                │
   │ • All heads process in parallel, then concatenated                                                      │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

4. FEED FORWARD NETWORK:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Two-layer MLP with 4× expansion ratio                                                                  │
   │ • Pattern: Linear(768 → 3072) → GELU → Linear(3072 → 768)                                              │
   │ • GELU activation: smoother than ReLU, non-zero gradient for negative values                            │
   │ • Processes each position independently (position-wise)                                                  │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

5. DROPOUT REGULARIZATION:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Applied at 4 locations per block:                                                                      │
   │   - After token+position embeddings                                                                      │
   │   - After attention output projection                                                                    │
   │   - Within attention (after softmax)                                                                     │
   │   - After feed-forward network                                                                           │
   │ • Drop rate: 0.1 (10% of neurons randomly dropped during training)                                      │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

6. POSITIONAL ENCODING:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Learned positional embeddings (not sinusoidal like original Transformer)                              │
   │ • Each position (0 to 1023) has a unique learnable 768-dim vector                                       │
   │ • Added to token embeddings to provide position information                                              │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

7. CAUSAL MASKING:
   ┌─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ • Upper triangular mask applied to attention scores                                                      │
   │ • Prevents position i from attending to positions j > i                                                  │
   │ • Ensures autoregressive property: predicts next token using only previous tokens                        │
   │ • Implementation: masked positions set to -∞ before softmax                                              │
   └─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

Key Insight:
• Attention mechanism has O(L²) complexity → becomes bottleneck for long sequences
• This is why context length is limited to 1024 tokens in GPT-2
• Modern models use sparse attention, flash attention, etc. to reduce this
