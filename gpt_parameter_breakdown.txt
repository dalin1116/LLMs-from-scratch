                              KEY INSIGHTS
═══════════════════════════════════════════════════════════════════════════════════

1. PARAMETER DISTRIBUTION (without weight tying):
   - Embeddings (Token + Position): 39.4M (24.15%)
   - Transformer Blocks: 85.0M (52.15%)
   - Output Head: 38.6M (23.67%)
   - LayerNorm: 1.5K (negligible)

2. SINGLE TRANSFORMER BLOCK BREAKDOWN:
   - Multi-Head Attention: 2.36M (33.31%)
   - Feed Forward Network: 4.72M (66.65%)
   - LayerNorm (×2): 3.07K (0.04%)

3. COMPUTATIONAL HOTSPOTS:
   - Feed Forward layers consume 66.65% of each block's parameters
   - The 4× expansion (768 → 3072) creates significant computation
   - Multi-Head Attention: 4 projections (Q, K, V, output) of 768×768

4. OPTIMIZATION OPPORTUNITIES:
   - Weight Tying saves 38.6M parameters (23.67%)
   - Quantization (float32 → int8) reduces memory by 75%
   - Combined: Weight Tying + int8 can reduce from 622MB to ~119MB

5. ATTENTION MECHANISM DETAILS:
   - 12 attention heads
   - Each head operates on 64 dimensions (768/12)
   - Causal masking ensures autoregressive property
   - Each head learns different aspects of token relationships

6. RESIDUAL CONNECTIONS:
   - 2 residual connections per block (attention + feed forward)
   - Total: 24 residual connections across 12 blocks
   - Critical for gradient flow in deep networks
